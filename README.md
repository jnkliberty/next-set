# Next Set

My workout tracker for logging sets and seeing progress.

**Status: in progress.** The latest improvements are deployed privately and pass deployment checks. A real iPhone workout test remains. Import review is not complete.

- Log weight and reps beside the previous session's sets.
- Resume unfinished entries and follow superset rounds.
- Find favorite exercises and read why a target was suggested.
- Review workout totals, muscle groups, and progress for each lift.
